# DriveX — E-Commerce Web Application

DriveX is a two-person course capstone developed collaboratively by Ophir Agami and Shlomi Jereby.

## My Contributions — Ophir Agami

- Implemented the initial registration and login endpoints and interfaces.
- Added password hashing using bcryptjs.
- Connected the application to MongoDB.
- Defined the initial User and Product Mongoose schemas.
- Built the initial project and authentication structure.

## Team Project Scope

Together, the team developed an e-commerce platform featuring four data models, three user roles, product and order workflows, MongoDB aggregation queries, support-ticket management, and external API integrations.

## Technologies

Node.js, Express, MongoDB, Mongoose, JavaScript, HTML, CSS, and bcryptjs.
